# 飞鸽 · 局域网快传

**飞鸽传书 / IP Messenger 的现代开源实现。** 打开就能发现同一网段的同事，直接聊天、发图片、传文件和整个文件夹。无需注册账号，不经过云盘，聊天、图片和文件全程端到端加密。

当前版本：`2.1.0` · 平台：Linux / Windows · 许可证：MIT

## 项目用途

飞鸽传书最吸引人的地方是：不用加好友、不用登录、不用把文件上传到第三方服务器，同一局域网内打开就能互传。飞鸽把这件事带到了现代桌面环境。

它适合这些场景：

- 在办公室、机房或家庭局域网内快速传文件，不想经过网盘和聊天软件。
- 需要把整个文件夹原样发给同事，包括子目录和空目录。
- 使用 Linux 桌面，想要一个界面现代、资料留在本机的局域网传输工具。
- 对隐私有要求，希望聊天和文件不经过第三方服务器。

飞鸽不是官方 IPMsg 客户端，也不是云聊天软件：它没有账号、好友系统、群聊、离线消息或服务端存储。

## 功能

### 自动发现

- 启动后自动寻找同一局域网内的其他飞鸽设备，无需输入 IP 或添加好友。
- 重启软件后，同一台设备仍显示为同一个联系人。
- 联系人列表区分在线、离线和历史联系人；支持按别名、指纹或 IP 搜索。
- 可选跨网段连接，详见[跨网段](#跨网段)。

### 即时消息

- 一对一文字聊天，支持送达状态、未读角标和按时间分组。
- `Enter` 发送，`Shift + Enter` 换行。
- 新消息到达时播放提示音；窗口未聚焦时显示系统通知。
- 对方离线时不能发送，界面会明确提示。

### 图片消息

- 点击图片按钮选择图片，或直接按 `Ctrl + V` 粘贴截图。
- 发送前可以预览、填写说明，再确认发送。
- 支持 PNG / JPEG / GIF / WebP / BMP，原图上限 20 MB。
- 接收端自动接收图片并显示缩略图；点击可查看大图。
- 右键可转存图片，或在文件夹中定位原图。

### 文件与文件夹

- 支持单文件、多文件、整个文件夹，也可以直接把文件拖进聊天窗口。
- 文件夹会保留完整目录结构和空目录；重名时自动生成 `文件夹 (1)`，不会覆盖已有文件。
- 接收方可先看到文件数量、总大小和部分预览，再决定是否接收。
- 传输中心显示进行中、等待接收和最近完成的传输，可查看速度、进度、取消传输或打开接收目录。
- 可开启“自动接收文件”，收到的文件和文件夹直接保存到指定目录。
- 图片始终自动接收；普通文件默认需要确认。

### 本地聊天记录

- 文字消息、文件摘要和图片缩略图会自动保存在本机。
- 支持聊天记录搜索、分页加载更早消息和一键清空。
- 每个联系人保留最近约 5000 条消息。
- 聊天记录在本地加密保存，未解锁时无法读取。

### 身份认证

- 每个联系人都显示身份指纹。
- 未认证的联系人会显示“未认证”标记，并使用不同的卡片配色。
- 点击“认证身份”，双方核对 6 位安全码；确认后联系人标记为“已认证”。
- 认证后可以设置只保存在本机的联系人别名。
- 已认证关系会被记住，对方重新上线后自动恢复，不需要每次重新核对。
- 同名但身份不同的设备不会合并，避免认错人。

### 桌面体验

- 深色 / 浅色主题。
- 关闭窗口时隐藏到系统托盘，托盘菜单可重新显示或退出。
- 收到消息或文件请求时播放提示音；窗口未聚焦时显示系统通知。
- 单实例运行：重复启动会唤起已有窗口。
- 按 `/` 快速聚焦联系人搜索框。

## 开始使用

### 安装

飞鸽提供 Linux x64 AppImage 和 Windows x64 便携版。Linux 下赋予执行权限后直接运行 AppImage；Windows 下双击便携版程序即可，无需安装。

### 第一次启动

1. 启动飞鸽。
2. 设置本地密码（至少 6 位）。它用于加密本机资料，不会上传，也无法找回。
3. 如果系统钥匙串可用，可以勾选“下次免密进入”。
4. 点击左上角自己的卡片或底部设置按钮，修改昵称和接收目录。
5. 确保两台设备在同一局域网，并按系统提示允许飞鸽通过防火墙。
6. 几秒后左侧会出现在线同事；点击即可开始聊天或发送文件。

> 如果系统防火墙需要手动放行，请允许飞鸽使用 UDP 和 TCP `24250`。

### 发送文字

1. 在左侧选择一个在线联系人。
2. 输入文字，按 `Enter` 发送。
3. 消息右下角的双勾表示对方已经收到。
4. 未读消息会在联系人卡片上显示角标。

### 发送图片

1. 点击输入框左侧的图片按钮，或按 `Ctrl + V` 粘贴截图。
2. 在预览窗口确认图片，填写可选说明，点击“发送图片”。
3. 接收端会自动接收并显示缩略图；原图保存在接收目录。
4. 点击缩略图查看大图；右键可转存或在文件夹中显示。

### 发送文件或文件夹

1. 点击“发送文件 / 发送文件夹”，或把文件、文件夹拖进当前聊天窗口。
2. 接收端会在聊天中看到文件卡片，在传输中心看到待接收请求。
3. 点击“接收”后开始传输，文件保存到设置中的接收目录。
4. 传输过程中可以查看进度、速度和已传输大小，也可以取消。
5. 完成后点击“打开文件夹”即可定位接收目录。

> 文件请求不会自动弹出确认框，避免打断当前工作。请在聊天卡片或传输中心点击“接收”。

### 认证身份

1. 打开与对方的会话，点击右上角“认证身份”。
2. 双方会看到相同的 6 位安全码。
3. 通过当面、电话或另一个可信渠道核对。
4. 双方确认后，联系人变为“已认证”，并可以设置本地别名。
5. 再次连接时，已认证关系会自动恢复。

**加密和身份认证是两件事**：第一次发送消息时，飞鸽会自动建立临时加密会话，内容已经加密；只有核对 6 位码后，才能确认对方确实是自称的那个人。

### 聊天记录与托盘

- 底部时钟按钮打开聊天记录，支持搜索、加载更早消息和清空全部记录。
- 关闭窗口不会退出飞鸽，而是隐藏到系统托盘。
- 需要彻底退出时，使用托盘菜单中的“退出飞鸽”。
- 如果桌面不支持托盘，关闭窗口会直接退出应用。

## 安全性与实现

飞鸽的安全目标很明确：**聊天、图片和文件内容不经过第三方服务器，内容始终加密，并且可以验证对方身份。**

### 保护的内容

- 聊天文字、图片和文件内容不会被同一局域网内的抓包者读取。
- 设备发现信息、联系人资料和加密握手不能被伪造或篡改。
- 本地聊天记录、身份私钥、联系人和认证关系在磁盘上加密保存。
- 即使使用 Hub 跨网段，Hub 也看不到聊天、图片和文件内容。

### 本地资料加密

首次启动时设置的本地密码不会被保存。它通过 `scrypt` 派生一把密钥，用这把密钥包裹一个随机生成的数据密钥；本机资料再用数据密钥通过 AES-256-GCM 加密。

- 加密范围包括：设置、身份私钥、联系人别名、认证关系和聊天记录。
- 修改本地密码只会重新包裹数据密钥，不会重新加密所有聊天记录。
- 勾选“下次免密进入”时，数据密钥由系统钥匙串保护；Linux 需要可用的安全钥匙串后端。
- 密码错误时无法进入，也不会加载本机资料。
- **忘记密码无法恢复**：没有后门，也没有服务端重置。

### 身份与签名

每台设备有一对 Ed25519 长期密钥：

- 公钥经过编码后就是设备身份，联系人按公钥区分，而不是按昵称或 IP。
- 私钥只保存在本机，并随本地资料一起加密。
- 设备信息、上线状态和资料更新都带签名。
- 接收方会校验签名、来源和时间，并拒绝重复的旧消息。

因此，同一网段的人可以看到你的昵称、主机名和 IP，但无法冒充你的身份修改联系人资料或伪造上线状态。

### 端到端加密

所有聊天、图片和文件都通过加密会话传输。

第一次给某个联系人发送内容时，如果没有现成会话，飞鸽会自动建立一次性临时会话：

1. 双方各自生成临时 X25519 密钥。
2. 双方先提交密钥的哈希承诺，再公开临时公钥，避免被中间人利用。
3. 通过 ECDH 协商共享秘密，再用 HKDF-SHA256 派生双向 AES-256-GCM 密钥。
4. 双方用 Ed25519 长期身份私钥签署完整握手过程，并互相验签。
5. 会话建立后，每条消息、每个图片和文件分块都使用 AES-256-GCM 加密。

握手签名绑定了双方身份、临时公钥和会话内容。中间人没有双方私钥，无法伪造签名，也就无法完成会话。

加密会话不可用时，发送会失败并提示，不会改用其他通道传输内容。

### 6 位安全码与持久认证

临时加密会话只保证内容加密，不代表已经确认对方是谁。点击“认证身份”后：

1. 双方根据握手结果得到相同的 6 位安全码。
2. 通过当面、电话或其他可信渠道核对这 6 位数字。
3. 双方确认后，飞鸽会保存一份高强度的认证密钥。
4. 对方重新上线或应用重启后，用这份认证密钥自动恢复加密会话，不需要每次重新核对。

6 位码只有约 20 bit，它的作用是把公钥和真人绑定，不能当作强密码使用。真正阻止中间人的是握手签名和临时密钥协商。

### 文件与 Hub

- 文件信息、完整清单和文件内容都在同一条加密通道中传输。
- 文件分块加密发送，接收端会校验大小和顺序。
- Hub 只帮助设备互相发现和建立直连，不保存消息、不转发文件，也不维护在线列表。
- Hub 能看到连接元数据（IP、时间、连接信息），但看不到聊天、图片或文件内容。

### 安全边界

- 飞鸽不防御已被控制的电脑、录屏、恶意软件或对方主动转发。
- 局域网发现信息和 Hub 连接会暴露部分元数据（昵称、主机名、IP、端口、连接时间）；加密保护的是内容，不是匿名性。
- 6 位安全码必须人工核对；跳过核对时，内容仍然加密，但无法确认对方身份。
- 自定义加密协议使用标准密码学原语，但尚未经过外部安全审计。
- 设备时间偏差过大会影响签名校验，请保持系统时间准确。

## 跨网段

同一局域网内，飞鸽会直接发现并连接同事。

如果同事不在同一局域网，需要管理员部署一台 Hub 服务器。在设置中填写 Hub 地址后，飞鸽可以通过 Hub 发现同事并建立直连。

- Hub 只负责发现和帮助建立直连，不读取或转发聊天、图片和文件内容。
- 消息和文件仍然在双方设备之间直连传输。
- 部分企业网络或严格防火墙环境可能无法建立直连，此时需要网络管理员协助。

## 数据与隐私

- 飞鸽不提供账号，不连接云端，不上传聊天记录或文件。
- 聊天记录、身份私钥、联系人、认证关系和设置全部保存在本机。
- 本地资料默认目录：
  - Linux：`~/.config/飞鸽/`
  - Windows：`%APPDATA%\飞鸽\`
- 本地密码用于加密这些资料；忘记密码时无法解密，只能删除数据目录重新开始。
- 删除数据目录会同时丢失身份、认证关系和聊天记录，同事端会看到一个新身份。

## 常见问题

**看不到同事？**

确认两台设备在同一局域网、没有开启客户端隔离，并允许飞鸽通过防火墙。VPN 或虚拟网卡也可能影响自动发现。

**对方收不到文件？**

确认防火墙允许飞鸽通信、接收目录可写、磁盘空间充足。文件请求需要在聊天卡片或传输中心点击“接收”，除非已经开启自动接收。

**忘记本地密码怎么办？**

无法找回。密码只用于本机解密，没有后门，也没有服务端重置。只能删除数据目录后重新开始。

**为什么不能启用“下次免密进入”？**

系统钥匙串不可用时无法启用。Linux 需要可用的安全钥匙串后端；系统钥匙串不可用，仍然可以输入本地密码解锁。

**“未认证”是不是消息没有加密？**

不是。第一次发送时飞鸽会自动建立临时加密会话，内容已经加密。“未认证”只表示还没有核对 6 位安全码，无法确认对方身份。

**能和官方 IPMsg 或其他飞鸽版本互传吗？**

不能。飞鸽使用自己的协议，双方都需要安装飞鸽并使用相同版本。

**跨网段可以用吗？**

可以，但需要管理员部署 Hub。部分企业网络或严格防火墙环境可能无法建立直连。

**关闭窗口后为什么还在运行？**

关闭窗口只会隐藏到系统托盘，飞鸽仍在接收消息。需要彻底退出时，使用托盘菜单“退出飞鸽”。

**Windows 提示“未知发布者”怎么办？**

当前构建没有代码签名，SmartScreen 可能提示未知发布者。确认文件来源可信后，选择“更多信息 → 仍要运行”。

**设备时间不一致会怎样？**

签名校验依赖系统时间。时间偏差过大会导致消息被丢弃，请开启系统时间同步。

## 已知限制

- 只支持一对一，没有群聊、频道或广播消息。
- 不支持离线消息：对方离线时无法发送。
- 官方构建面向 Linux x64 和 Windows x64，没有移动端或 macOS 安装包。
- 跨网段需要 Hub；部分企业网络或严格防火墙环境可能无法直连。
- 图片原图上限 20 MB；单次传输最多 200,000 个条目。
- 局域网发现会暴露昵称、主机名、IP 和端口等元数据。
- 本地密码无法找回，忘记密码将永久失去本机资料。
